系统介绍

项目概述

油签机系统 是一个基于Spring Boot的自动化签到解决方案，专门为学生设计。 系统需要用户提供自己的账号和密码，系统对密码高度加密,作者承诺不会泄露任何人的密码,仅仅用于签到。 如果不知道登录账户和密码的话,可以访问西石大官网的统一登录页面。
!!!本系统仅供学习测试,切勿非法使用!!! 访问XSYU 访问统一登录页面 访问油学通网页 访问项目仓库

主要功能

用户认证

安全的登录登出机制

一键签到

批量处理所有签到任务

自动签到

设置自动签到免去手动操作

签到记录

查看历史签到记录

使用指南

1

用户登录

用户名username是个人学号,登录采用XSYU官网统一账号密码

2

信息设置

邮箱用于通知签到结果,name用于显示通知昵称

3

查看签到

可以分页条件查看所有签到

4

执行签到

使用一键签到或单独处理每个签到任务,传递参数通过调用签到API返回的信息获取

5

设置自动化

开启自动签到功能，系统会在周日-周四每天晚上自动处理签到

使用流程

主流程
1 用户登录：身份验证
2 更新信息：完善资料
3 选择模式：自动/手动
自动模式
设置自动签到开关
系统后台自动处理
无需手动操作干预
手动模式
一键签到：批量完成所有
获取信息：查看签到详情
精准签到：单个处理
退出流程
停止使用系统
用户安全登出
注销登录信息

技术特性

Spring Boot AES强加密 RESTful API 响应式设计 限流保护 MyBatis Plus

快速开始

# 本地运行：
# 从github拉取项目
git clone https://github.com/hongchuwudi/xsyu-sign.git

# 1. 启动后端服务
./mvnw spring-boot:run

# 2. 访问系统
http://localhost:11451

# 3. 开始使用左侧菜单测试接口

用户登录

GET /user/login

用户登录并注册签到信息

username string 必需
用户名
psd string 必需
密码

自动签到设置

GET /user/auto-sign/{username}/{isAuto}

设置是否自动签到(每天晚上6:30-8:00随机时刻自动签到)

username string 必需
用户名
isAuto boolean 必需
是否自动签到 (true/false)

用户登出

GET /user/logout/{username}

用户登出-清理数据库的所有登录信息

username string 必需
用户名

更新用户信息

POST /user/info/{username}

更新用户基本信息

username string 必需
用户名
name string
姓名
email string
邮箱

获取所有签到

GET /sign/allSign/{username}

获取用户的所有签到任务列表

username string 必需
用户名
page integer 默认: 1
页码
size integer 默认: 10
每页数量

一键签到

GET /sign/all/{username}

一键执行所有签到任务

username string 必需
用户名

获取单个签到

GET /sign/oneSign/{username}/{signId}/{schoolId}

获取指定签到的详细信息

username string 必需
用户名
signId string 必需
签到ID
schoolId string 必需
学校ID

处理单个签到

GET /sign/one

处理单个签到任务

username string 必需
用户名
id string 必需
ID,通过获取查看某个签到信息来获取这个字段的值
signId string 必需
签到ID,通过获取单个签到接口获取这个字段的值
schoolId string 必需
学校ID,默认为17不用动
